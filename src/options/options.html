Google Docs Dark Mode

Set the colours Docs is themed with, or import them from a gg-theme tokens.json. The washes, tints and soft colours are derived from these the way gg-theme derives them. Saving reloads open documents.

Allow user scripts

The extension themes Docs with a script that runs in the page, which Chrome runs only once you turn on Allow User Scripts on the extension's details page. This notice goes away once it is on.
